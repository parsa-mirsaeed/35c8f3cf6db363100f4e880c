# Teacher guide — enabled scope only

Teachers can work within their authorized school/class context to:

- view assigned classes and students;
- create, update, publish and delete owned assignments;
- review student submissions for owned assignments;
- grade submissions and provide feedback;
- view authorized student grades;
- manage supported class materials and vectorization status;
- select/search governed knowledge assets available to their teaching context;
- initiate assignment personalization when an approved AI profile is enabled;
- use notifications/preferences and profile-change request flows.

Cross-school or non-owned object IDs are not a supported access mechanism and are denied by server authorization. AI availability is optional; a provider outage must not be described as an outage of core class/assignment/grading service.

Attendance, timetable, school reports and parent/teacher messaging are not enabled teacher capabilities.
