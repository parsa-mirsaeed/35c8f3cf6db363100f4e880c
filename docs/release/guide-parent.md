# Parent guide — enabled scope only

A Parent account is limited to linked child context. Supported views include child overview/stats and authorized child assignments/grades exposed by the current product.

Parents do not receive a general school reporting system and do not have an enabled parent/teacher messaging feature in the first contracted scope. `parent_reports` and `parent_teacher_communication` remain Disabled in the product capability manifest.

If a requested child or object is not linked to the authenticated parent, server authorization is expected to deny access regardless of a URL/object identifier supplied by the browser.
