# Student guide — enabled scope only

Students can use their authorized account to:

- view their classes and assigned work;
- open personalized/assigned assignment details when authorized;
- submit work for their own assigned object;
- view their own class grades and persisted teacher feedback where exposed;
- view supported class materials;
- use notifications/preferences and profile-change request flows.

Students cannot submit to another student's assignment or read another student's grades by changing an object ID.

Attendance workflow, timetable/schedule management, grade-trend analytics and derived academic metrics are Disabled and must not be represented as available student features.
